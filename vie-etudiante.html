Vie étudiante et débouchés

Ce que les étudiants construisent pendant leur formation, avec quels outils, et où cela peut les mener.

Des projets concrets

Ce site

Un site de présentation du département, réalisé en groupe avec Git : un dépôt, une branche par membre, des commits documentés et des Pull Requests relues avant la fusion.

ERIS Inscriptions

Une petite API Java qui calcule les frais d'inscription. Les tests sont écrits avant le code, le projet se construit avec une seule commande Maven, et il est prêt à recevoir un pipeline d'intégration continue.

Les outils du quotidien

Git et GitHub
Versionner le code, travailler sur des branches, relire les Pull Requests.
Maven et JUnit
Compiler, tester et empaqueter un projet Java en une commande.
Éditeurs de code
Visual Studio Code, IntelliJ ou Eclipse selon le langage.
Linux et terminal
Administrer une machine et automatiser des tâches.
Docker
Empaqueter une application pour qu'elle s'exécute de la même façon partout.

Débouchés

Les diplômés peuvent viser des postes dans les opérateurs de télécommunications, les banques, les administrations, les entreprises de services numériques et les start-up.

  • Développeur

    Conçoit et maintient des applications web, mobiles ou métiers.

  • Administrateur réseaux

    Installe, configure et surveille l'infrastructure réseau d'une organisation.

  • Analyste en cybersécurité

    Détecte les menaces, corrige les failles et répond aux incidents.

  • Ingénieur DevOps

    Automatise la construction, les tests et le déploiement des logiciels.

  • Analyste de données

    Prépare et interprète des données pour aider à décider.

Quatre habitudes qui aident

  • Écrire un peu de code chaque semaine, même hors des séances.
  • Utiliser Git dès le premier projet, avec des messages de commit lisibles.
  • Lire un message d'erreur en entier avant de chercher une solution.
  • Relire le code de ses camarades : on y apprend autant qu'en écrivant le sien.
